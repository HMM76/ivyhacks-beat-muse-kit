# IvyHacks: Beat Muse — send kit

Register link: https://luma.com/d60fjmjy

## Send it

1. Open https://hmm76.github.io/ivyhacks-beat-muse-kit/
2. Click **Copy email**.
3. Paste into a new message in Gmail / Apple Mail / Outlook.
4. Subject: `Beat Muse. Win $4K.`
5. Send.

## Got it as an email? Just forward it.

Gmail, Outlook and Apple Mail keep the header, the facts and the button when you forward. Add one line on top in your own words.

## Listservs that strip HTML (Penn Mailman lists, some Google Groups)

Paste `plain.txt` as the body and attach `cover.jpg`.

## Slack / GroupMe / Discord / Instagram

Post `cover.jpg` with the text from `plain.txt` as the caption.

## Files

- `index.html` — the email with the Copy button
- `plain.txt` — text-only version
- `hero_banner.jpg` — 1200×700 email header, served from this repo so it loads in every inbox
- `cover.jpg` — the Luma cover, 1200×1200, for chats and socials
- `make_assets.py` — regenerates the header if the copy changes
